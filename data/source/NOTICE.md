# MPLADS source snapshot

This directory contains `MPLADS.csv`, a checked-in snapshot of the public MPLADS work list.

- Upstream dataset: https://github.com/Vonter/india-mplads-works
- Upstream public source: https://www.mplads.gov.in/mplads/
- License: Open Data Commons Open Database License (ODbL-1.0)
- License text: `ODbL-1.0-LICENSE`

The API preserves the source record and labels fields that are absent from this snapshot. It does not infer coordinates, images, or fraud conclusions from missing data.
